# Traxx Navbar Component

This directory contains the standalone Traxx navigation bar component.

## Files in this Directory

- `navbar-snippet.html`: The clean, drop-in HTML `<header>` block for the floating pill navbar and responsive mobile menu.
- `navbar.css`: The extracted CSS rules for the floating pill layout, backdrop blur, brand logo, responsive breakpoints, and mobile dropdown.
- `navbar.js`: The JavaScript logic for mobile menu toggling and scroll detection.
- `index.html`: Standalone interactive preview page.
